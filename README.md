# Neon Streets

**An open-world GTA-style crime game built with Three.js**

## Play Now

Open `game/index.html` in a modern browser (Chrome/Firefox recommended).

Or use the included server:
```bash
node serve.js
# Visit http://localhost:8080
```

## Controls

**On Foot:**
- WASD - Move
- Shift - Sprint
- Space - Jump
- Mouse - Look around
- E - Enter/exit vehicle

**Driving:**
- W/S - Accelerate/brake
- A/D - Steer
- Shift - Brake
- Space - Handbrake

## Features

- Procedurally generated city (Crimson Bay)
- 6 drivable vehicle types
- 5-star wanted system with police pursuit
- Traffic AI (30 vehicles)
- Pedestrians (50 NPCs)
- Arcade-style vehicle physics
- Full day exploration

## Technical

- **Engine**: Three.js (vendored)
- **Language**: Plain JavaScript ES6 modules
- **Build**: Zero build step required
- **Assets**: Fully procedural (no external assets)
